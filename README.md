# حرب السفن 2000 — Battleship 2000

لعبة معركة السفن بأسلوب ألعاب الكمبيوتر أيام الألفين: سفن ثلاثية الأبعاد، بحر متموج، أصوات وموسيقى مولّدة داخل اللعبة، وواجهة عربية.

- العب ضد الكمبيوتر (سهل / عادي / صعب)
- أو العب مع صديقك أونلاين: «غرفة جديدة» ثم «نسخ رابط الدعوة» وأرسله له. الجهازان يتصلان مباشرة (WebRTC) بدون حساب أو تثبيت.

العب الآن: https://juuzoou1.github.io/battleship-2000/
